Privacy Policy

Last updated: 15 September 2026

Shorts Pipeline ("the App") is a personal, self-hosted tool that turns long YouTube videos into vertical short clips. It is operated by Tio Fani for his own single-account use. This policy explains what Google user data the App accesses and how it is handled.

What the App accesses

With your explicit consent through Google OAuth 2.0, the App requests these scopes:

  • https://www.googleapis.com/auth/youtube.upload — to upload generated clips to your own YouTube channel.
  • https://www.googleapis.com/auth/youtube.readonly — to read basic channel information (channel name, handle, thumbnail) so the App can display which channel is connected.

The App does not request or access Gmail, Drive, Calendar, Contacts, or any other Google service. It does not read your private videos, comments, subscribers, messages, or analytics beyond the basic channel identity listed above.

How the data is used

  • Uploaded clips are published to the YouTube channel that authorised the App, at the privacy setting chosen by the operator.
  • Channel identity is displayed locally in the App's interface so the operator can confirm the correct channel is linked.

Data is used solely to operate the App for its operator. It is not used for advertising, profiling, or any other purpose.

How the data is stored

  • The OAuth refresh token is stored on the operator's own private server in a file readable only by the server's own account (filesystem mode 600).
  • Tokens and credentials are never transmitted to any third party and never sent to any remote service other than Google's own OAuth and YouTube Data API endpoints.
  • No Google user data is sold, rented, shared, or disclosed to any third party.

Limited Use disclosure

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

  • The stored refresh token remains until the operator disconnects the channel in the App's Settings, which deletes it immediately.
  • You may revoke the App's access at any time at myaccount.google.com/permissions. Revoking access invalidates the stored token and the App stops working until re-authorised.
  • Generated video files live on the operator's private server and can be deleted at any time.

Data collected by this website

This website is a set of static pages. It sets no cookies, runs no analytics, and collects no personal information.

Children

The App is not directed to children and is not available for public sign-up.

Any change to this policy will be published on this page with a revised date.
